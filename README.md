# B站直播｜粉丝牌面板 + 进房自动换牌

点 B 站直播间的原生粉丝牌图标即可打开完整粉丝牌面板，进入直播间时自动佩戴该主播的粉丝牌。设置项在直播页面内的设置窗口中修改，点「保存」后生效。

## 功能说明

- **进房自动换牌**：识别房间号与主播，自动佩戴本房间的粉丝牌；暂时读不到时会按 5s / 15s / 30s / 60s 重试，切回页面或更换房间时重新执行。
- **完整粉丝牌面板**：全部徽章、头像、等级、亲密度进度、今日亲密度，以及佩戴中 / 当前房间 / 最近获得标记。
- **面板操作**：点击佩戴、再点取消、滚动翻页、搜索（支持拼音首字母）、跳主播空间 / 直播间、装扮中心入口、不佩戴勋章。
- **网页内设置窗口**：点油猴菜单「展开设置」或面板底部「设置」，在直播页面上显示全部设置项；改动先存为草稿，点「保存」后写入并生效，取消 / 关闭窗口即放弃修改。
- **设置项**：进房自动换牌、成功后提示、没牌子时切回默认牌、默认牌（可从列表选择，或用当前房间的牌子）、面板入口方式（原生图标 / 悬浮小按钮 / 两者都有）。
- **快捷操作**：打开面板（Alt+M）、立即重新换一次、查看运行状态、复制诊断信息。
- **B 站原版弹窗**：面板底部「B站原版」临时放开接管，用一次真实点击打开 B 站自己的弹窗。
- **显示与兜底**：自动适配深色模式；面板贴右侧栏、底边停在聊天输入框上沿，不遮挡直播画面；原生图标找不到时自动退回悬浮「牌」按钮，Alt+M 始终可用。

## 使用说明

1. 在浏览器中安装 Tampermonkey、Violentmonkey 等用户脚本管理器，并登录 B 站。
2. 按下方「安装」一节装好脚本。
3. 进入任意直播间，点聊天框旁的原生粉丝牌图标打开面板，或按 `Alt+M`。
4. 修改设置：点油猴菜单「展开设置」（或面板底部「设置」）→ 在网页里的设置窗口中修改 → 点「保存」。
5. 想用 B 站原版弹窗：点面板底部「B站原版」→ 再点一下高亮的原生粉丝牌图标。
6. 出问题时用设置窗口里的「复制诊断信息」，把内容发给维护者即可定位。

## 数据与边界

- 数据全部来自 B 站官方接口；脚本只读取接口，只发送「佩戴 / 取消佩戴」两类请求。
- 不发送弹幕、不送礼、不改动 B 站页面业务逻辑；不做频控绕过、行为模拟或指纹伪造。
- 配置项保存在脚本管理器的本地存储中，不上传服务器。
- 隐私说明：脚本不收集、不上传任何个人信息；仅在本机读取登录 cookie 中的 csrf 用于完成佩戴请求，诊断信息需用户主动点击复制才会生成。
- 免责声明：本脚本为个人使用的辅助工具，与哔哩哔哩官方无关。使用第三方脚本可能不符合 B 站用户协议或相关规则，账号限制、功能异常等风险由使用者自行承担；B 站页面或接口改版可能导致脚本失效，维护者不保证持续可用。
